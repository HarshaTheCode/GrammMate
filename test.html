GrammMate Testing Bench

Use this page to test the text selection and correction features.

How to use:
  1. Ensure the extension is loaded unpackaged in your browser.
  2. Make sure you set your API key in the extension options page (click the extension icon in your browser toolbar to open it).
  3. Select/highlight some text with errors inside any of the fields below.
  4. Click the floating ✨ button launcher that appears near your selection, then click ✨ Fix Grammar!
